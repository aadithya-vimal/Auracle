# Auracle — Trustless Sentiment Oracle Protocol

> **Decentralized AI-powered sentiment analysis for crypto markets, published directly on the Solana blockchain.**

---

## The Problem

Crypto traders rely on sentiment analysis from centralized sources — APIs, dashboards, and newsletters controlled by single entities. These can be manipulated, delayed, or taken offline. There is no trustless, verifiable way to consume market sentiment on-chain.

## Our Solution

**Auracle** is a decentralized oracle that:

1. **Ingests social signals** from crypto market feeds (tweets, posts, community discussions)
2. **Analyzes sentiment using AI** via Groq's ultra-fast inference API running Meta LLama 3
3. **Publishes the score on-chain** as a verifiable Solana transaction through an Anchor smart contract
4. **Displays a live dashboard** that reads directly from the blockchain — fully trustless, no backend API

The result is a **tamper-proof sentiment feed** that anyone can query without trusting a centralized provider.

## Tech Stack

| Layer | Technology | Purpose |
|-------|-----------|---------|
| **Data Ingestion** | Python 3.10+, JSON corpus | Aggregate and normalize social signals |
| **AI Analysis** | Groq API, Meta LLama 3 | Multi-dimensional sentiment scoring (0-100) |
| **Smart Contract** | Solana, Anchor Framework, Rust | On-chain storage with authorized oracle updates |
| **Frontend** | React 18, Vite, Framer Motion | Trustless dashboard reading directly from chain |
| **Wallet** | Phantom / Solflare | Direct on-chain interaction (Devnet) |

---

## What Makes It Different

- **Trustless**: The frontend reads directly from the Solana blockchain account via RPC — no backend API, no intermediary
- **Verifiable**: Every sentiment update is a signed Solana transaction, cryptographically attributable to the oracle
- **AI-Powered**: Uses Groq's sub-100ms inference for real-time LLM-based sentiment analysis
- **Transparent**: Full audit trail — raw data corpus, keyword extraction, confidence scoring, and on-chain history

## Quick Start

### Prerequisites

- Node.js 18+
- Python 3.10+
- Phantom or Solflare wallet (set to Devnet)
- Groq API key (free at [console.groq.com](https://console.groq.com))

### 1. Install Frontend

```bash
cd app
npm install
```

### 2. Install Oracle

```bash
cd oracle
pip install groq solana solders python-dotenv requests
```

### 3. Configure Environment

Create `oracle/.env`:

```env
GROQ_API_KEY=your_groq_api_key
SOLANA_RPC_URL=https://api.devnet.solana.com
PROGRAM_ID=DgjQCmPvs3FHSk3DdPskVy6zifMC93LqWe3en7jEmtzF
ORACLE_PRIVATE_KEY=[your,wallet,private,key,array]
SENTIMENT_ACCOUNT=4RgDj27rUJiQRyP3Hx4RzEoK1afks9PrVr52rgThNK9W
```

### 4. Run Both Processes

**Terminal 1 — Frontend:**
```bash
cd app
npm run dev
```

**Terminal 2 — Oracle Agent:**
```bash
cd oracle
python oracle_agent.py
```

### 5. Open Dashboard

Navigate to **http://localhost:5173** and connect your wallet (Devnet).

## Oracle Pipeline Detail

Each cycle (every 60 seconds):

1. **Sample** — Select 50 data points from the corpus
2. **Extract** — Identify sentiment-bearing keywords and normalize text
3. **Analyze** — Send to Groq LLM for multi-dimensional scoring
4. **Score** — Compute weighted sentiment score (0-100) with confidence
5. **Sign** — Create Solana transaction with oracle keypair (Ed25519)
6. **Commit** — Submit `update_sentiment` instruction to the Anchor program
7. **Log** — Write `analysis_log.json` with full breakdown to `app/public/`
